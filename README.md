# UrbanPulse: Saudi Smart Mobility & Traffic Analytics

A spatial data analysis project exploring traffic density, peak hours, and smart city mobility across major Saudi cities using Power BI.

## Project Overview
UrbanPulse is designed to analyze urban traffic patterns and monitor congestion levels in key Saudi hubs (including Riyadh, Jeddah, Dammam, Al Khobar, Jazan, and Abha) to support smart city planning and infrastructure management.

## Key Features
- **Spatial Data Integration:** Utilizes geographic coordinates (Latitude & Longitude) for location-based traffic mapping.
- **Interactive Dashboard (Power BI):** Visualizes traffic density levels (High, Medium, Low) and peak operational hours.
- **Temporal Analysis:** Evaluates traffic fluctuations across different days of the week and times of the day.

## Repository Contents
- `UrbanPulse_Saudi_Data.xlsx`: Cleaned structured dataset containing spatial and temporal traffic metrics.
- `UrbanPulse_Presentation.pdf`: Final project presentation deck detailing the methodology, insights, and strategic recommendations.

## Tools & Technologies
- **Power BI:** Data visualization and dashboard design.
- **Excel:** Data preparation and structuring.
- **Geospatial Analytics:** Coordinate-based mapping for urban insights.
